# Contribution Guidelines

## Introduction

Thank you for your interest in the project!

If you have an interest in contributing to Empower, then feel free to create an issue or a PR, and I will try my best to look into it as early as I can.

## General considerations

Before sending a PR, please ensure that "cargo test" passes and that there are no "compiler hints".
(Feel free to add additional tests if relevant for your feature)

## AI & Agents

Code quality and stability are what matter, not how the code is written. 

Use of agents is therefore fine, but the person contributing the code is naturally responsible for the result.

Commit messages and PR descriptions should be carefully reviewed by the contributor.
